# IITM-WEBSITE
This is a beginner-level HTML project based on an IIT Madras college website.

## Pages Included

- Home
- Courses
- Faculty
- Fees
- Admission
- Gallery
- Contact

## Features

- College information
- Course details
- Faculty information
- Fee structure
- Online admission form
- Basic HTML navigation

## Technologies Used

- HTML5

## Purpose

This project was created to practice HTML concepts such as headings, paragraphs, links, tables, forms, images, and page navigation.
